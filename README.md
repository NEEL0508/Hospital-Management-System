# Hospital Management System

A modern, responsive Hospital Management System frontend built with React and Vite. This application provides a seamless user interface for patients to access medical services, register, and log in to their health dashboard.

## Features

- **Modern Landing Page**: A visually appealing home page showcasing the hospital's priority, expert statistics, and medical services.
- **Patient Registration**: A comprehensive registration form for new patients to create an account, complete with input validation UI and secure password fields.
- **Patient Login**: A secure login portal to access the health dashboard, featuring role-based access visual indicators (Admin, Doctor, Patient).
- **Responsive Design**: Fully responsive layout ensuring a great user experience across desktop, tablet, and mobile devices.
- **Client-Side Routing**: Smooth and fast navigation between pages using React Router.

## Technologies Used

- **React**: Frontend UI library for building component-based interfaces.
- **Vite**: Next-generation frontend tooling for fast build times and hot module replacement.
- **React Router DOM**: Declarative routing for React web applications.
- **Lucide React**: Beautiful and consistent icon set used throughout the application.
- **Vanilla CSS**: Custom CSS with CSS variables for dynamic theming and styling.

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

- Node.js (v18 or higher recommended)
- npm (Node Package Manager)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/NEEL0508/Hospital-Management-System.git
   ```

2. Navigate to the project directory:
   ```bash
   cd Hospital-Management-System
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

4. Start the development server:
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173` to view the application.
